# Od wypłaty do wypłaty - legal documents

Public privacy policy and Google Play publishing notes for the Android app **Od wypłaty do wypłaty** / **From Payday to Payday**.

GitHub Pages entry point:

- Polish: `https://pawel223531.github.io/od-wyplaty-do-wyplaty-legal/`
- English: `https://pawel223531.github.io/od-wyplaty-do-wyplaty-legal/en/`

The app stores user-entered budget data locally on the device. It uses Google Mobile Ads SDK for banner and interstitial ads.
